## 💡 Example Problem

### Find the Second Smallest Number

```python
numbers = [10, 5, 8, 3, 20, 7]

unique_numbers = list(set(numbers))
unique_numbers.sort()

print("Second smallest:", unique_numbers[1])
```

### Output

```text
Second smallest: 5
```
